# 云渲染新核心

> 设计确认：2026-10-20。本文维护新核心的目标、模块边界与设计契约；当前实现见 [云](clouds.md)，实施状态、下一步与验收见 [新核心待办](backlog.md#云渲染新核心)。

## 目标与边界

目标是在地面、穿云、高速飞行和轨道升降中，同时改善视觉表现与 GPU 成本。逐步替换密度查询、太阳光照和采样重建，保留游戏接入、行星环境、深度与合成契约；旧路径用于对照和回退，收益以测量为准。

## 可选分布与多星球

**全球云分布必须可选。** 无全球覆盖贴图、stock 云图或地球资源的其他星球也必须能独立工作。

- 程序化 / 预设分布可独立使用；全球数据显式接入。开启新核心不隐式开启全球分布，也不改变 stock 开关语义。
- 全球输入关闭或缺失时继续程序化回退，不把整层密度乘零；通道有效性与缺图契约见 [分布规则](clouds.md#体积分布与光照)。
- 分布随行星 / 预设管理；半径、云高、厚度、密度和光照取自当前行星与配置，不绑定地球尺度、云型或贴图尺寸。
- 精细体积、光照缓存与远景共用密度入口，同时支持程序化与可选全球数据。
- 跨绘制复用的缓存身份必须包含行星、云层 / 预设和数据版本；行星切换禁止复用前一星球的结果。

“全球分布可选”只约束数据来源；球面几何、世界空间稳定性和跨尺度飞行支持始终保留。

## 密度与空区加速

以当前密度为基线建立可证明的密度上界，先覆盖解析支持带，再评估空间层级；只跳过证明为空的查询，有云区域仍用正式密度。加速不按镜头方向、FOV 或帧号改变云形。

高斯高度带没有严格的 `height ± spread` 零边界，不能用 `TryGetBand` 硬裁，也不能把少量采样均为零当成整个空间块为空。保守界必须覆盖细节侵蚀、warp、分布和风运动；若采用非零误差阈值，需明确误差预算与薄云 / 云边验证。

沿用 [mip 0 与密度消费者契约](clouds.md#体积分布与光照)。加速界不能以粗密度替代原云形；新密度模型作为明确的新模式评估。

## 太阳光照缓存

世界空间光学厚度 / 透射率缓存复用太阳光照，近景、云缘及剧烈变化处保留局部追光修正。缓存表达云内不同位置的衰减，单张地表投影图不能替代云内自遮挡。

采用有限覆盖，按对照结果评估多级精度或分块；不要求整个行星的高精度体素常驻显存。布局、更新预算与修正方式按实测选择。

- 失效输入包括太阳方向、密度参数 / 分布版本、云风运动、行星和预设；浮动原点需保持世界位置对应或明确失效。
- 高速移动或新区域进入时补建并提供追光回退，不用冻结阴影换帧率。
- 同区域可评估复用；远处 PIP 覆盖不足时补建或回退，屏幕历史仍按相机隔离。
- 总预算包含创建、更新、采样、回退、显存及移动 / 切换峰值。

缓存光照属于近似算法，需对照现有追光结果评估厚云内部、云缘、晨昏与太阳变化；不能沿用纯纹理复制优化的逐像素等价承诺。

## 采样重建与光照层次

联合设计真实亚像素射线、云运动补偿、历史置信度、遮挡拒绝和邻域约束；静止积累细节，转向、缩放、穿云和新露出区域补足新采样，不能用历史权重掩盖运动错误。

重投影必须覆盖完整云风场，特别是纬度相关的南北风非刚性位移。新增采样不能破坏 [时序与镜头稳定性](clouds.md#时序与镜头稳定性) 的深度、投影和失效约定。

分开处理太阳直射、天空遮蔽、多次散射近似与银边，保留单段透射率积分。HDR 辐亮度 / 历史需计入带宽、曝光和合成适配成本，用节省的预算改善层次。

## 云型与同源远景

近景与远景共用分布和垂直结构；评估由体积推导的预积分等简化，保持覆盖、光学厚度和球面地平线光程一致。关闭全球分布时仍由程序化 / 预设提供同源数据。

云型结构、细节侵蚀和反平铺在新核心成本可控后评估。反平铺要维持世界稳定与各密度消费者一致，并计入额外采样；过渡曲线只能缓和表示差异，不能替代同源设计。具体噪声、曲线和远景格式尚不固定。

## 集成与对照

接入边界遵守 [架构](architecture.md#生命周期与模块边界) 与 [当前云契约](clouds.md)：包括近远深度、绘制时机、透射率、雾和反射。新核心不能让天气反向改写云配置，也不能恢复已删除的独立行星编排器。

新路径显式选择，旧 XML 不因缺少新字段就被自动改为新算法。新增配置按 [配置与预设](architecture.md#配置与预设) 完整接入复制、限值、持久化和三语 UI；不同密度 / 光照参数的迁移应明确，不能按“值恰好等于旧默认”猜测用户意图。

按 [测量方法](development.md#按改动选择验证) 建立固定镜头对照，比较同画质耗时与同预算画质；阶段及判据只见 [待办](backlog.md#云渲染新核心)。完整集成验收后再考虑默认切换。

## 技术参考

- [Guerrilla：Nubis³](https://www.guerrilla-games.com/read/nubis-cubed)：距离场步进加速、光照采样与可穿行云体的建模参考；其数据布局和性能数字不直接代表本项目。
- [Guerrilla：Nubis, Evolved](https://www.guerrilla-games.com/read/nubis-evolved)：近距离与高速云体场景的采样和时序取舍参考。
- [Epic：Volumetric Clouds](https://dev.epicgames.com/documentation/unreal-engine/volumetric-clouds?application_version=4.27)：二次追光、Beer 阴影贴图、多次散射近似和地面到太空模式的取舍参考。
