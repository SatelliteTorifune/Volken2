| 南北风重投影 | 密度中的纬度衰减偏移未完整进入空间重投影；共用 include 仍有风方向 TODO，需验证完整变换 |
| 雨方向剩余边界 | 有符号速度修复只在表面锁定 / 变体关闭场景获确认。移动参考帧的 `FrameSurfaceVelocity` 补偿与非零长宽变体缩放未解决 |

## 已确定顺序但尚未实现的云方案

【决策：2026-10-11】先改 2D–3D 过渡曲线，再引入共用反平铺。适配不同半径、云顶和大气条件，暂缓全球覆盖 / 法线贴图及相关新配置。

**过渡曲线候选**：沿用每层起止海拔，令 `u` 为 0~1 进度、`H(s)=6s⁵−15s⁴+10s³`（输入先 clamp），以 `k=0.25` 作对照起点：

```text
e2D = H(u / k)
e3D = 1 - H((u - k) / (1 - k))
w2D = e2D / max(e2D + e3D, ε)
w3D = 1 - w2D
```

颜色与透射率用同一互补权重；`u=0.25` 时 w2D=0.5，不是纯轨道。保留旧曲线作基线、0.001 / 0.999 分派、历史失效、Orbit 缺失回退和反射纯体积。按完整升降检查覆盖 / 亮度 / 跳变和双路径耗时；曲线不能补足壳面缺少体积的问题。

**反平铺候选**：稳定云空间三角网格 + 整数 hash 偏移 + 三份噪声加权，shape / detail、完整 / 廉价密度、云影查询、反射和可选轨道 albedo 共用 helper。宏观轨道覆盖继续使用现有分布，不重新由短周期切片决定轮廓。默认关闭，旧 XML 保持原采样。

网格与相位不依赖相机 / FOV / 帧号，world→云空间和 warp 各应用一次。验证两半球、极区、投影接缝、浮动原点、噪声均值 / 方差 / 最终覆盖、多相机与 GPU 毫秒。主要 shape+detail 读取可能从 2 次增至 6 次，不能作为免费性能优化。稳定性未过时不启用球面方案。

参考底账：历史本机 KSA 核对读取 `Content/Core/Shaders/Clouds/CloudAntiTiling.glsl`、`RaymarchedTo2DFade.glsl`、`CloudFunctions.glsl` 及 `Astronomicals.xml`。KSA 地球共用 4096² 覆盖图和配套法线；原权重为 `clamp(4u)` 与 `clamp(1.33(1-u))`，并不互补，不能直接塞入 Volken 的 lerp。以上是历史源码调查，未移植，也未作 KSA 运行性能对照。

## 性能候选

先按 [测量规则](development.md#按改动选择验证) 分离 CPU / Render / GPU 瓶颈。下表均未实现或未完成性能证明，排序表示建议先测的场景；不自动改变用户默认值或旧 XML。

| 候选 | 收益触发 / 实施边界 |
|---|---|
| 云光采样预算 | 用既有参数对照 25 / 12 / 6，比较厚云自阴影和 GPU 耗时；光步长已独立，不能仅凭旧值等于默认值迁移 |
| 雨碰撞捕获 | 分别量 tagged / physical 捕获与 Prepare / Resolve。降低图尺寸不等比例降低 CPU 几何提交；不能删除无标签物理层捕获 |
| 仅碰撞的快照省略 | 水花关闭时评估省掉旧位置快照 / 旧表面查询，仍保留当前帧碰撞和清池 |
| 雨 FillArgs | 当前 kernel 无可见剔除，只原子加已知 amount。可评估容量 / 数量变化时由 CPU 写 count；后续若真做可见列表需改回 GPU 计数 |
| 完全透明雨的视觉停工 | transparency=1 时仍有模拟 / 碰撞 / 绘制；候选门控保留雨声和主视图环境量，恢复时重置冻结粒子 / 碰撞历史 |
| 分叉对象池 / 集中寿命 / 合批 | 默认 85、极限 549 条分叉，材质已共享但 GameObject / LineRenderer 仍分散；先量雷击尖峰，合批保持朝向、多相机和材质所有权，Renderer 数不是实测 DrawCall |
| 云带区间裁剪 | 球面求交排序将预算集中带内；高斯无硬边界，先推保守密度界 / 误差阈值，不能按 TryGetBand 硬裁 |
| 密度与光照缓存 | 光照专用简化、LUT、连续空域步长、Light Volume、PlaceRays 属长期候选；世界密度 / mip 0 约束继续有效，新增采样与失效逻辑需单独证明 |
