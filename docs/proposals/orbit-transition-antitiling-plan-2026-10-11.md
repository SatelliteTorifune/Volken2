# Volken 2D–3D 过渡曲线与反平铺采样提案

> 状态:📋 实施顺序与范围已确定;曲线与采样算法为待验证方案,尚未实施、未测新增 GPU 耗时。
> 日期:2026-10-11
> 定位:适用于不同半径、云层高度和大气条件的行星,改善轨道云衔接与程序化噪声重复。
> 关联:[KSA 参考复核](ksa-orbit-cloud-reference-audit-2026-10-11.md) §3.2、§3.3、[当前噪声修复](../cloud-visibility-diagnosis-2026-10-10.md) §12、[轨道云历史](../archive/orbit-clouds-crossfade-2026-08-27.md)。

【决策:2026-10-11】先引入更好的 **2D–3D 过渡曲线**,完成对照后再引入 **反平铺采样**。暂不增加全球覆盖 / 法线贴图及相关配置,也不要求地球式云分布资源。此前参考复核的全球贴图优先建议由本提案接管推进顺序。

后续用户授权的[噪声修复](../cloud-visibility-diagnosis-2026-10-10.md) §10~§11 的主噪声替换与固定粗化被用户否定画质,最新 §12 已恢复旧体积 Worley / mip 0,轨道覆盖改由现有宏观分布决定,保留镜头与 TSS 稳定性修复。当前 177 项回归通过,未新增全球贴图配置。本提案的过渡曲线与真正反平铺仍未实施;后续采样必须保证同一世界位置不会随 FOV / 朝向改变密度,不能用静态颗粒指标替代镜头运动验证。

## 1. 引入更好的 2D–3D 过渡曲线

### 1.1 现状与目标

[CloudRenderer.cs](../../Assets/Scripts/Volken/Clouds/CloudRenderer.cs) 的 `ComputeOrbitFade` 当前将相机海拔归一化后计算 `u²(3−2u)`;[Clouds.shader](../../Assets/Scripts/Volken/Clouds/Shader/Clouds.shader) 的 Composite 用这个值混合两份云颜色与透射率。过渡带内两种云都绘制,高空纯 2D 时跳过体积 raymarch 与 TSS。

目标是让 2D 表示更早参与,保留一段 3D 细节退出的缓冲,减少上升 / 下降时突兀的观感变化。曲线只能改变两种表示的占比;壳面单次采样与体积积分存在轮廓差异,不能靠改曲线保证形状完全相同或消除所有变薄。

KSA 的实际表达式为 `w2D=clamp(4u)`、`w3D=clamp(1.33(1−u))`,权重和可接近 2。借鉴其先后节奏,适配 Volken 当前合成时采用**归一化的阶段包络**,避免重复累加同一片云的亮度 / 遮挡。

### 1.2 候选曲线

沿用每层已有的起点 / 终点海拔,用无量纲进度描述曲线。首轮候选如下,`k=0.25` 是对照起点,不是所有行星的最终标定值:

```text
u = clamp((cameraAltitude − startAltitude) / (endAltitude − startAltitude), 0, 1)
H(t) = 6s⁵ − 15s⁴ + 10s³, s = clamp(t, 0, 1)
k = 0.25
e2D = H(u / k)
e3D = 1 − H((u − k) / (1 − k))
w2D = e2D / max(e2D + e3D, ε)
w3D = 1 − w2D
```

`H` 的一、二阶导数在端点为零;两段包络衔接平滑。2D 包络在前 25% 完成,之后 3D 包络退出;**归一化后 u=0.25 时最终 2D 权重为 0.5**,并非已经纯 2D。这是适配当前混合方式的推导,不是 KSA 原曲线的等价移植。

| 高度带进度 u | 当前 smoothstep 的 2D 权重 | 候选的 2D 权重 |
|---|---|---|
| 0 | 0 | 0 |
| 0.125 | 0.043 | 0.333 |
| 0.25 | 0.156 | 0.500 |
| 0.50 | 0.500 | 0.559 |
| 0.75 | 0.844 | 0.827 |
| 1 | 1 | 1 |

候选有更早介入和中段缓冲的特点,也可能过早暴露 2D 的轮廓差异。以完整升降过程选择曲线和 `k`,不能只凭静止中点截图判定改善。首轮保留旧曲线作基线,不额外引入逐帧低通 / 滞后状态。

### 1.3 接入与行星适配

- **合成**:继续将 `w2D` 传给 `_OrbitFade`;颜色与透射率使用同一权重。Additive 混合云光,Standard 同步混合云光与透射率;无云保持 `(0,0,0,1)`,同层的两种表示不作为两个独立物理云层再次叠加。
- **雾与遮挡**:保留各自的体积云深度 / 轨道壳面距离,先按各自距离求雾贡献再用同一权重混合;不把两种深度平均后查雾,不重复雾化背景。前景遮挡、多层合成顺序和每层材质归属沿用现有契约。
- **分派与历史**:是否绘制 2D、是否跳过体积 / TSS 均由最终权重决定,保留现有 0.001 / 0.999 端点收口与进出纯轨道态的历史处理。轨道 Pass 不可用时回退纯体积;TSS 开关、RT 重建和每相机资源不能改变曲线语义。
- **不同类型行星**:沿用每行星 / 每层预设的海拔起止值,不硬编码地球高度,也不按行星半径直接等比放大。云层高度仍由 `TryGetBand` 定义;厚大气 / 高云顶预设须核对过渡位置与云顶关系,避免在云内过早切成壳面。
- **配置兼容**:拟提供可回退的新曲线模式,旧 XML 缺少字段时维持旧曲线;`k` 限制在远离 0 / 1 的安全范围,海拔终点大于起点。变更走配置复制 / 限值 / 静态参数修订路径,每相机历史按现有机制失效;首轮不增加复杂 UI。

### 1.4 成本与验收

曲线每相机每层仅增加少量标量运算,无新增纹理、RT 或 raymarch 步数。主要成本仍是过渡带同时绘制 2D / 3D;曲线变化会改变达到分派阈值的高度,因此不能直接承诺总帧时间不变。

验收使用旧 / 新曲线分别完成相同路径的上升、下降和过渡边界停留,记录平均亮度、覆盖、画面跳变及两条管线 GPU 时间。组合覆盖 Additive / Standard、雾开 / 关、TSS 开 / 关、主相机 / PIP、多云层、云内 / 云上与无云像素;水面反射当前固定 `_OrbitFade=0`,应验证不受曲线切换影响。端点须恢复纯 3D / 纯 2D,不再出现丢云、残留历史或中段异常增亮。

## 2. 引入反平铺采样

### 2.1 现状与目标

当前两张 128³ shape / detail 为原 Worley FBM 周期纹理,保留完整 mip;体积 / 光照 / 云影 / 反射已恢复 mip 0,stock 也恢复 mip 0。轨道覆盖与浮雕只读现有分布,共享噪声空间均值标定,可选 albedo 仍读局部细节。随镜头改变密度的足迹过滤与瓦片退场已经撤回;宏观轨道表示没有实施真正反平铺。

反平铺目标是让仍可分辨的体积与可选 albedo 细节保留自然变化、打散明显的周期排列。它不能恢复已经小于像素的细节,也不保证两种表示的轮廓一致;以最新固定世界场为基线,分别比较重复度、轮廓与覆盖变化。

### 2.2 候选算法与共用规则

采用 KSA 的**三角网格 + 稳定整数 hash 偏移 + 三次噪声采样加权**思路,整理为共用 shader helper:

1. 取减去行星中心、按现有云旋转变换后的坐标,生成球面方向与稳定网格位置。网格尺度由该层固定参考半径和噪声频率决定,约与 `Rref × noiseScale` 成正比;小行星至少保留有效网格,大行星避免整数溢出和浮点精度损失。不要用每个采样点的径向高度改变网格分辨率。
2. 找到网格三角形的三个顶点和重心权重;对顶点整数坐标、固定种子和尺度标识做 hash,生成三个纹理相位偏移。hash 不依赖屏幕像素、相机、帧号或 TSS 采样格。
3. 用同一基础噪声坐标加三个偏移读取 3D 纹理,按归一化权重混合。shape / detail 采用一致规则,各自使用对应频率与标识;有限幅度的权重锐化可缓解混合变糊,其方差 / 覆盖影响必须对照标定。
4. 体积完整密度、廉价密度 / 光照查询、云影、反射和可选轨道 albedo 调用同一 helper;同一云空间点和尺度得到同一相位。轨道宏观覆盖与三次差分继续查询现有分布,不重新引入短周期局部噪声作为轮廓。由反平铺导致的体积云量变化与过渡差异单独对照。

KSA 的方向映射代码包含简化投影,不能视为已经证明全球无接缝。适配必须验证两半球、极区、投影折叠边和网格边:同一球面边界两侧的顶点身份、偏移与权重要连续,只补坐标折叠不足以证明连续。未通过时不启用该球面方案。

现有 world → 云空间变换和 domain warp 只应用一次;网格、相位与旋转保持同一约定。大坐标优先沿用行星相对 / 浮动原点路径,不对绝对世界坐标做浮点 hash。切换行星、预设、种子或尺度触发静态参数修订 / TSS 历史失效;相机移动和原点重置不得重新随机化噪声。已知 N/S 风重投影缺口另案处理,本提案不能把它视为已解决。

### 2.3 过滤与性能预算

- 三份偏移样本先沿用 §12 的体积 mip 0 与可选 albedo 固定世界 LOD;网格权重和 hash 只依赖云空间坐标,不能引入 FOV / 朝向 / TSS 依赖,不能在离散 hash 上直接求导。
- 第一版不恢复随像素足迹向平均值退场;额外 albedo 的五倍频率继续使用固定 LOD 补偿,强度为零时跳过。屏幕空间抗锯齿应在重建或积分层另行验证,避免在覆盖阈值前改变云场。
- 体积 / 反射 / 轨道同时以固定世界场为基线,先隔离反平铺的效果与成本。任何新增过滤须重复同一世界射线的 FOV / 偏转 / roll / 分辨率验证;flow map 和新全球纹理链留给其他提案。

| 位置 | 当前主要噪声读取 | 三采样后的主要噪声读取 | 放大成本的因素 |
|---|---|---|---|
| 一次体积密度查询 | shape + detail,约 2 次 | 约 6 次 | 每条视线多步、光照密度查询、反射、云层与相机数 |
| 轨道中心 + 两邻点覆盖 | shape / detail 最后 mip 均值共 2 次,三点共用 | 仍为 2 次,不接入反平铺 | 三次现有分布查询、浮雕差分、分辨率、云层与相机数 |
| 轨道额外 albedo | 细节有效时约 1 次 | 约 3 次 | 五倍频率、细节强度 |

以上只计主要噪声相位读取,不含分布纹理、trilinear 的底层取样及新增 hash / 权重运算。接入反平铺的局部噪声读取约三倍,宏观轨道覆盖不增加相位读取;不代表整帧耗时或 FPS 变成三倍 / 三分之一。实际受缓存、步数和 GPU 限制影响,须实测。复用已有噪声与 mip 时不新增常驻大贴图或 RT。

反平铺拟设为每层可关闭、默认关闭的独立选项,旧预设维持原采样。开启时相关 2D / 3D 消费点一起生效;性能不足先回退整个选项,再评估只对 detail 反平铺等减采样版本,不靠只改一个视图隐藏成本。

### 2.4 验收

- **重复与形状**:同一场景 / 噪声 / 参数下比较关闭 / 开启,记录周期偏移相关性、噪声均值 / 方差、最终覆盖和平均亮度;观察轮廓、浮雕是否出现网格或变糊。不得用常量纹理测试替代真实 128³ 多 octave 噪声。
- **全球与行星差异**:测试南北半球、极区、投影接缝、星球轮廓,以及小半径、高云顶、厚大气 / 巨行星预设;使用程序化输入也能独立完成验证,不以地球覆盖图作为前置条件。
- **时序与视图**:固定云空间点的相位一致,旋转 / 缩放连续;主相机、PIP、反射在同一位置读取一致。测试浮动原点、切行星 / 预设、TSS 与分辨率切换,无噪声游动、随机跳变或旧历史污染。
- **GPU**:分别测纯体积、过渡带、纯轨道,主相机与多相机;固定分辨率、层数、视线 / 光照步进预算。记录云各 Pass 的 GPU 毫秒、整帧时间与峰值,再决定默认建议和可接受档位;当前未给出百分比收益。

## 3. 交付顺序与实施边界

| 阶段 | 交付内容 | 进入下一阶段的条件 |
|---|---|---|
| 1:过渡曲线 | 旧曲线基线、候选模式、端点 / 分派 / 历史回归、升降对照 | 无增亮 / 丢云 / 历史回归,确认过渡节奏与成本 |
| 2:反平铺 | 共用 helper、默认关闭选项、真实噪声全球 / 形状 / GPU 对照 | 接缝与稳定性通过,重复减少且覆盖变化与耗时可接受 |

两阶段分开验证,避免同时改变混合权重和密度场而无法归因。既有全球分布路径可继续作为原预设输入;本提案不新增全球贴图配置、资产依赖或法线缓存。当前 177 项云回归属于已实施的可见性 / 镜头稳定性 / 画质回退修复,不算本提案的实现验证;过渡曲线与反平铺仍待实施。
