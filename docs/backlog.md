## 已知缺口

| 问题 | 当前证据 / 下一步 |
|---|---|
| 夜云星空穿透、灰团与明暗真实性 | Additive 不衰减背景；体积环境入射缺少云内遮蔽，仍与银边强度耦合。先核对最终天空 / 透射率合成，再评估环境遮蔽与银边解耦；独立月光输入未接入 |
| 周期噪声、2D–3D 轮廓差异 | Worley 周期仍在，输出重建只减轻欠采样；壳面不等同于体积积分。纳入[新核心阶段三](#云渲染新核心)的云型与同源远景验收 |
| 南北风重投影 | 密度中的纬度衰减偏移未完整进入空间重投影；共用 include 仍有风方向 TODO，需验证完整变换 |
| 雨方向剩余边界 | 有符号速度修复只在表面锁定 / 变体关闭场景获确认。移动参考帧的 `FrameSurfaceVelocity` 补偿与非零长宽变体缩放未解决 |
| 自适应雨域密度下降 | 半径扩大但容量固定，当前接受此代价；保持不在渲染回调自动重建 buffer |
| 原生透明和反射雾 | 水面 / 玻璃 / 折射 / 机体反射未适配；当前仅阻止反射误用主相机雾。云首命中近似需云内、多层和地平线评估 |
| 碰撞表示边界 | 单层捕获缺少多层几何，薄结构可能漏碰撞，移动表面水花会漂移；观察其他飞行器的 PIP 仍用玩家 craft 样本 |
| 行星映射整体重写 | 云和天气共用 `PlanetConfigList.xml`，多入口整表保存；合并 / 并发失效风险待评估，尚未做持久化拆分 |

星环与云 / 水绘制顺序、Craft 高轨道云 scale 属于旧用户报告，本轮未运行游戏复现；在确认现状前保留为待调查，不写成已证实当前缺陷。

## 性能候选

先按 [测量规则](development.md#按改动选择验证) 分离 CPU / Render / GPU 瓶颈。下表均未实现或未完成性能证明，排序表示建议先测的场景；不自动改变用户默认值或旧 XML。

| 候选 | 收益触发 / 实施边界 |
|---|---|
| 雨碰撞捕获 | 分别量 tagged / physical 捕获与 Prepare / Resolve。降低图尺寸不等比例降低 CPU 几何提交；不能删除无标签物理层捕获 |
| 仅碰撞的快照省略 | 水花关闭时评估省掉旧位置快照 / 旧表面查询，仍保留当前帧碰撞和清池 |
| 完全透明雨的视觉停工 | transparency=1 时仍有模拟 / 碰撞 / 绘制；候选门控保留雨声和主视图环境量，恢复时重置冻结粒子 / 碰撞历史 |
| 分叉对象池 / 集中寿命 / 合批 | 默认 85、极限 549 条分叉，材质已共享但 GameObject / LineRenderer 仍分散；先量雷击尖峰，合批保持朝向、多相机和材质所有权，Renderer 数不是实测 DrawCall |
| 反射与 PIP 预算 | 反射已粗步进，无 TSS；可评估自身分辨率 / 减少逐层回写，PIP 雨量 / 碰撞质量独立于主视图，不复用旧投影图冒充降频 |
| CPU 小项 | pass / 属性 ID、重复环境计算、不变音量写入和每秒相机扫描缓存，仅按 Profiler 证据推进 |

【保留决定：2026-10-02】拖 UI 时 buffer / RT 重建的 A 组优化按此前用户决定不做；不得因旧热点清单继续把它自动纳入本轮实施。
